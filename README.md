# Paul Henry – Professional Portfolio

Senior Project Manager | Programme Delivery | Business Change & Transformation

Static multi-page site for GitHub Pages.

## Pages

- **Home** – Profile, impact highlights, core capabilities, career snapshot
- **Experience** – Full professional timeline and qualifications
- **Case Studies** – STAR examples (Portfolio Reporting Framework, GalanCEAmine, Dancing with Daffodils)
- **Skills** – Capability matrix and selected strengths
- **Contact** – Phone, email, location

## Deploy to GitHub Pages

1. Create a new repository (e.g. `paul-henry-portfolio` or `username.github.io`).
2. Upload the contents of this folder (or push via git).
3. In the repository **Settings → Pages**, set source to the branch containing these files (usually `main`) and folder `/ (root)`.
4. Your site will be available at `https://<username>.github.io/<repo>/` (or the custom domain if configured).

## Local preview

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Customisation

- Update contact details in `contact.html` and the footer of each page.
- Replace `background.jpg`, `career-timeline.jpg` and `skills-matrix.jpg` if desired.
- Edit `styles.css` to adjust colours (CSS variables at the top).
